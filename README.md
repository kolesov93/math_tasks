Коллекция математических задач, решений и программ. Каждая задача хранится в отдельной папке: `01`, `02`, …, `13`.

Для самостоятельного решения откройте PDF и прочитайте первую страницу: решение начинается с новой страницы. В №06 подсказка также вынесена на отдельную страницу. В №02 пока есть только условие и рисунок.

## Структура и добавление задач

- `main.tex` — исходник условия, рисунков и решения; текст редактируется здесь.
- `main.pdf` — готовая версия для чтения и отправки по ссылке.
- `main.cpp` — программа, если она нужна для задачи.

Новая задача получает следующий свободный номер. Для номеров меньше 10 используется ведущий ноль. После добавления задачи нужно внести строку в каталог и пересобрать её PDF. Перед решением и каждым его альтернативным вариантом ставится `\clearpage`.

Общий сборник в будущем можно собирать из этих же материалов; второй экземпляр текста вручную вести не нужно.

## Сборка PDF

Нужны LaTeX с поддержкой русского языка, TikZ, `tkz-euclide` и `latexmk`. Запускать сборку нужно из папки задачи: у программных задач `main.tex` подключает соседний `main.cpp`.

Например, из корня репозитория:

```sh
cd 13
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```
